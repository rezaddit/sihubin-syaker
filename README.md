# React + Vite

## Cara Install

### 1. Install NodeJS
Download dari https://nodejs.org (versi LTS)

Cek instalasi:
```bash
node -v
npm -v
```

### 3. Masuk ke Folder Project
```bash
cd (folder sihubin-syakernya)
```

### 4. Install Dependency
```bash
npm install
```

### 5. Jalankan Project
```bash
npm run dev
```

Buka di browser:
```
http://localhost:5173
```
